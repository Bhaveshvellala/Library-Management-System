# Library Management System (C++)

A console-based library management system written in C++. It uses a `Book` class, `std::vector` for dynamic storage, and file handling so data is saved between runs.

## Features
- Add new books with unique ID
- Search books by exact title or author
- Issue and return books
- Update book details
- Delete books
- Display all books in the library
- save and load book details using file handling
- Input validation: invalid or non-numeric input is rejected and re-asked

## Concepts used
- Classes and objects
- Vectors
- File handling
- Functions and loops
- Input validation

## How to run
Open the project in a C++ IDE, compile the program, and run it.

## Menu
1. Add New Book
2. Search Book
3. Issue Book
4. Return Book
5. Display All Books
6. Update Book Details
7. Delete Book
8. Exit

## Possible improvements
- Case-insensitive and partial search
- Track issued copies per book
- Organize the code using separate header and source files
